## Why NumPy?

NumPy is one of the most important libraries in the Python data science ecosystem because it provides:

- Fast numerical computations
- Efficient handling of large datasets
- Support for multidimensional arrays
- Built-in mathematical and statistical functions
- A foundation for libraries like **Pandas, SciPy, and Scikit-learn**

---

## Python Lists vs NumPy Arrays

| Feature | Python Lists | NumPy Arrays |
|--------|-------------|--------------|
| Speed | Slower | Faster |
| Memory usage | Higher | Lower |
| Mathematical operations | Limited | Vectorized operations |
| Multidimensional arrays | Difficult | Easy |
| Use case | General programming | Scientific computing |
