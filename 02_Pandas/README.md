## Why Pandas?

Pandas is widely used in Data Science because it provides:

- Easy handling of **structured data**
- Powerful **data manipulation and cleaning**
- Efficient **data filtering and grouping**
- Built-in support for **data analysis operations**
- Integration with libraries like **NumPy, Matplotlib, and Scikit-learn**

---

## Python Lists vs Pandas DataFrame

| Feature | Python Lists | Pandas DataFrame |
|--------|-------------|------------------|
| Data Structure | Simple lists | Tabular data (rows & columns) |
| Data Analysis | Difficult | Easy |
| Filtering | Manual loops | Built-in operations |
| Handling Missing Data | Difficult | Built-in functions |
| Use Case | General programming | Data analysis |
