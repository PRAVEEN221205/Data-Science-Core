# 🛒 BigMart Sales Forecasting using Machine Learning

## 📌 Project Overview
This project predicts the sales of products across various BigMart stores using Machine Learning. The objective is to analyze historical sales data, perform data preprocessing and feature engineering, and build a regression model that accurately forecasts product sales.

---

## 🎯 Objectives
- Understand and analyze the BigMart sales dataset.
- Perform data cleaning and preprocessing.
- Engineer relevant features for better model performance.
- Build and evaluate machine learning regression models.
- Predict product outlet sales.

---

## 📂 Dataset
The dataset contains information about products sold at different BigMart outlets, including:

- Item Identifier
- Item Weight
- Item Fat Content
- Item Visibility
- Item Type
- Item MRP
- Outlet Identifier
- Outlet Size
- Outlet Location Type
- Outlet Type
- Outlet Establishment Year
- Item Outlet Sales (Target Variable)
